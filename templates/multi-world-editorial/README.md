# Multi-world Editorial

首个公开模板，来自真实长视频制作中已经证明有效的视觉语言，但不包含原视频、原文案或个人品牌。

## 核心特征

- 16:9、1920×1080、30fps。
- 米白编辑部作为呼吸与总结空间。
- 学术蓝、实践绿、商业黑金、梅子紫用于区分不同叙事世界。
- 人物可以全屏、居中圆框或完全退出画面。
- 大标题只承担观点，卡片和流程承担解释。
- 每个动作都要表达关系：比较、推进、组合、聚合或选择。

## 从成熟版本保留的东西

- 圆形人物框的可调居中裁切。
- 多背景世界切换，而不是全片一个黑色模板。
- 钩子、卡片、流程、网络、总结五种版式。
- 整片和独立素材双导出。
- 预览帧与解码验收。

## 没有复制的东西

- 私人口播内容、字幕、账号名称和头像。
- 本机绝对路径。
- 原视频和输出成片。
- 针对某一条稿子的 16 个硬编码镜头。

## 可调参数

任务单中可调：

- `brandName`、主色与强调色；
- `presenter.cropX`、`cropY`、`scale`；
- 场景类型、世界、时长、人物模式和源视频起始帧；
- 标题、副标题、要点与强调词。
